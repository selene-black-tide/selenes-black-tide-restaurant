# 角色1 文本试玩原型

> **状态：实验性原型，不是设定。**
> 目的是把「体力条」这条规则跑起来，看它能不能撑住一局。数值全部照抄
> 同目录的 `角色1-无脑灌伤.md` 和企划书，**没有一条是新的设计结论**。
> 原型自己补的规则都在下面单独列出，未拍板前不要写进企划书。

## 跑起来

```bash
python game.py                # 正常玩
python game.py --seed 42      # 固定随机种子，方便复盘
python game.py --stamina 70   # 改整局体力，测平衡用
python sim.py 300             # 机器人跑 300 局，出平衡数据
```

Python 3.8+，零第三方依赖。

## 两条已定的规则

- **整局体力 100 点**，出牌消耗，见底回店
- **所有卡牌耗 1 点体力**

一局最多出 100 张牌，打得越浪，走得越浅。

## 一局七层

```
入口·苔径 → 积水走廊 → 碎石阶 → 湿洞(三小只) → 巢穴外缘 → 精英·锈铁门 → 树心(大树精)
   敌怪1       敌怪2       敌怪3       三小只          敌怪5        精英1           Boss
```

每场打完：回 5 血 → 三选一加卡 → 继续。七层清完回店结算。

## 原型自补的规则（不是设定）

| 项 | 原型做法 | 为什么这么处理 |
|---|---|---|
| 省力 | 每第 4 张牌免费 | 全卡 1 体力，−25% 没法取整，用「四次免一次」近似 |
| 战斗后回血 | +5 | 50 血硬打七层必死，不回血测不出体力条的问题 |
| 三小只意图 | 三只各走固定循环 | 企划书里意图是并列写的，没指定哪只走哪条 |
| 失败 | 掉落全丢 | 待拍板 #8 的三个选项里先挑一个跑通 |
| 大树精缠绕 | 每层每回合扣 1 血 | 原文「每层缠绕每回合造成 1 点伤害」直译 |
| 精英2（史莱姆） | 未实现 | 合体链会带来无限分裂，先不放 |
| 遗物 / 事件房 / 卡牌升级 | 未实现 | 不影响验证体力条这条主线 |

## 平衡数据

`sim.py` 用一套简单策略（扛不住就防、扛得住就打）跑 300 局：

| 整局体力 | 通关率 | 平均推进 | 平均剩体力 |
|---|---|---|---|
| 100（当前默认） | 91.0% | 6.91 / 7 层 | 19.0 |
| 80 | 48.3% | 6.48 / 7 层 | 4.7 |
| 60 | 3.7% | 5.93 / 7 层 | 0.1 |
| 40 | 0% | 4.83 / 7 层 | 0 |

**结论**：100 偏宽松，基本能走完全程，体力条没有形成真正的取舍；**70–80 才是紧张区**，那时要在「多打一张牌」和「多走一层」之间做选择。

这条正好压到待拍板 **#4（体力条一池还是两池）**：现在是一池，出牌和续航共用一条，所以总数字直接决定一局能打多深。改成两池的话，这套模拟要拆成两套消耗表重跑。

## 已知没做的

- **房间消耗**：现在只有出牌扣体力，进房间不扣。加上之后体力才真的同时管「移动」和「出牌」
- **撤退**：房间之间跑路，带走已有掉落
- **遗物**：30 个的四分之一先做，验证会不会冲爆数值
- **掉落权重**：现在四类均等随机
