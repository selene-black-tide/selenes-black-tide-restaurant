# 00-overview · 项目总览

放**对外和对内都能看**的东西：企划书、项目简介、市场判断、竞品分析。

## ★ 游戏企划书 —— 整个项目最重要的一份

| 文件 | 是什么 | 能不能改 |
|---|---|---|
| [游戏企划书.docx](游戏企划书.docx) | **源文件**，Word 格式 | 只有 Mizuki 改 |
| [游戏企划书.md](游戏企划书.md) | 从 docx **自动导出**的镜像，给 AI 读 | **不能**，手改会被下次导出覆盖 |

| | |
|---|---|
| **地位** | 项目正式定稿，一切设计的最高依据 |
| **冲突** | 任何文档与它矛盾，以它为准 |
| **AI 怎么读** | 读 `.md`（docx 是二进制，直接读是乱码） |
| **AI 想改** | 不许。写进根目录 `游戏理念.md`，标 `（待并入企划书）`，由 Mizuki 并进 docx |

### 改完 docx 之后必须做的一步

在仓库根目录跑：

```powershell
python tools/export_plan.py
```

它会把 docx 重新导出成 `游戏企划书.md`。**忘了跑，AI 读到的就是旧版本**——这比没有镜像更糟，所以改完 docx 一定顺手跑一次。

脚本只做结构还原（把 124 个平铺段落按关键词提成标题），**不改写任何一个字**。新章节如果认不出标题，会原样降级成普通段落，不会丢内容。
