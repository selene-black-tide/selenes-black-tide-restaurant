# docs/ —— 文档区

这一层放**给人和 AI 读的正经文档**。临时草稿、抓取下来的网页、脚本输出一律放根目录的 `_tmp/`（已被 git 忽略）。

## 编号规则

数字前缀决定浏览顺序，间隔留 10 方便以后插新目录：

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `00-overview/` | 项目总览、企划书、对外介绍 | 具体系统设计 |
| `10-design/` | 系统设计、数值、关卡、剧情 | 美术工具选型、代码 |
| `20-art/` | 美术流程、AI 工具选型、资产规范 | 具体资产文件（放 `assets/`） |
| `30-tech/` | 技术方案、引擎选型、接口约定 | 代码本身（放 `src/`） |
| `90-archive/` | 废案、过期文档 | 还在用的东西 |

## 加一份新文档

1. 放到对应目录，文件名用中文（`系统-经营供给.md`）
2. 头部加 frontmatter，模板见 [10-design/_模板.md](10-design/_模板.md)
3. **回根目录改 [INDEX.md](../INDEX.md) 加一行**
4. 提交：`docs(范围): 新增 XXX`

## 注意

- `游戏理念.md` **不在这一层**，它在仓库根目录，是唯一事实来源（SOT），被每日自动化写入
- 作废的文档不要删，`status` 改 `废案` 后挪进 `90-archive/`
