# 色板试压指南

> 依据 [ADR 0004](../../decisions/0004-主色板Endesga64.md)：**试压通过之后才冻板**，冻板在批量出图之前。这份指南教你怎么试压、看什么、缺色怎么记。
> 只写操作和检查办法，不替组长判定「通过」。菜单名按 Aseprite 1.3 的中文/英文界面写，版本不同可能有出入，找不到就搜关键词。
> 不需要 PixelLab 付费，也不是批量出图。

## 0. 先认几个词

| 词 | 意思 |
|---|---|
| 色板（palette） | 全游戏允许用的颜色清单，这里是 69 色 |
| 试压 | 拿一张真实 NAI 原画，强行只用这 69 色重画一遍，看效果够不够用 |
| 索引色（Indexed） | 一种图片模式：图里每个像素不存颜色本身，只存「色板第几号」。所以图只能出现色板里的颜色 |
| 抖动（dithering） | 用两种颜色交错的小点模拟中间色。试压第一轮**关掉**，不然看不出缺色 |
| 色带（banding） | 本来平滑的渐变被压成一条一条的色块，说明中间的颜色不够 |
| 最近色匹配 | 压色时每个像素自动换成色板里「看起来最像」的那个颜色 |

## 1. 准备

1. 装好 Aseprite（组长工作流里用的像素编辑器）。
2. 色板文件在仓库的 `assets/palette/`（组长 11-28 指定放这里，Alvin 放进去的）：
   - `endesga64-plus5.hex`：69 色整套，每行一个色值，Aseprite 能读。**导入这个。**
   - `endesga64-plus5.gpl`：同一套 69 色的 GIMP 格式，别的软件用。
   - 个人目录 `alvinczq7-cell/art-prep/色板/` 里的 `Endesga64-补色.gpl` 只有 5 个补色，**不是整套，别当整套用**。
3. 三张测试原画（见第 3 节），都用 NAI 已有或新出的原画，不要网上随便找。
4. 记录表：复制本文第 4 节的表。

## 2. 操作步骤（每张图都这样做一遍）

**① 导入色板**
- Aseprite 里新建任意文件，右上色板面板左边的小按钮（≡ 菜单）→ `Load Palette…` / 载入调色板 → 选 `endesga64-plus5.hex`。
- 确认色板面板里有 69 个色块，数一下。

**② 把原画缩到目标大小**
- 打开 NAI 原画 → `Sprite → Sprite Size…`（精灵大小）。
- 按图的用途选尺寸（ADR 0002）：立绘高约 400；场景小人 48–64 高。**缩放方式选 Nearest-neighbor（最近邻）**，别选平滑的，不然会多出一堆杂色。
- 这一步只是为了贴近真实使用的像素密度，和 PixelLab 的 `Image to pixel art` 不是一回事。想完全走组长流程就先用 PixelLab 降像素，再回来做步骤 ③。

**③ 压到 69 色**
- `Sprite → Color Mode → Indexed…`（索引色模式）。
- 弹窗里：色板选「当前色板」（Current palette），抖动（Dithering）先选 **None（无）**。
- 确认。图片所有颜色会被换成色板里最近的色。
- 另存为 `试压_图名_无抖动.png`，别覆盖原图。

**④ 对比**
- 把原画和压后图并排放大 4~8 倍看（`View → Zoom`）。
- 建议再做一版带抖动的（Floyd-Steinberg 或 Ordered）存成 `_抖动.png`，只用来对比，不算最终结果。

**⑤ 找缺色**
- 看第 3 节每张图的「看什么」。
- 不确定哪里不对时，把压后图和原画在同一位置各取色（吸管工具，按 `I`），对比明度和色相差多少。

## 3. 三张测试图，各看什么

组长要的是各测一个短板：**紫魔法 / 草地植物 / 餐厅暖光**。

### 图一：带紫魔法

测的是：紫 / 洋红的明度阶梯（补色没动紫，全靠原板）。

看这些：
- 魔法光的渐变是否平滑，还是明显一条一条（色带）。
- 光晕最亮处和最暗处的紫，能不能分出至少 3 级。
- 紫和旁边其他颜色（青色魔法、蓝夜幕）交界处有没有变成脏灰。
- 紫色是否整体偏粉或偏蓝，和原画气质差多少。

### 图二：草地 / 植物

测的是：黄绿（补后 6 级）和绿（原板偏薄）。

看这些：
- 草地能否分出亮部、中间、阴影 3 级以上，还是糊成一片。
- **鲜艳度**：组长提醒「草地够用但不够鲜艳」，要看草地是否发暗。发暗就按她说的从黄绿补色里借，并如实记录。
- 绿色在阴影里往青色偏的那段（`5ac54f → 33984b → 1e6f50 → 134c4c`）是否自然，有没有突然跳到蓝绿。
- 4 个黄绿补色有没有被用到，用到的位置对不对；没用到也要记一句。

### 图三：餐厅暖光场景

测的是：肤色、暖棕、墙地板家具的明暗层次，以及 ADR 的「白天餐厅」取色表。

看这些：
- **肤色**：浅、中、深各一个人物（或同一人物的亮部、暗部），是否都有自然的亮面 / 中间调 / 阴影。深肤色补的 `6f462f` 有没有用上，够不够。
- 暖光（`ffeb57`）光斑旁边的渐变是否平滑。
- 木头、食物的棕橙层次是否保住，还是糊成一块。
- 对照 ADR 0004 第 5 节的白天取色表：墙 / 地板 / 家具 / 食物 / 皮肤 / 头发，实际压出来的色是否和表里写的一致，不一致就记下来。
- 同一角色在白天和午夜场景里，皮肤色应不变（ADR 要求）。

## 4. 缺色怎么记录

压完每张图填一行（缺多少记多少，没缺色也要写「未发现缺色」）：

| 图 | 位置 / 对象 | 现象 | 色系 | 现有最近色 | 候选补色（色值 / 明度 L） | 是否成套（3~5 级） | 备注 |
|---|---|---|---|---|---|---|---|
| 例：草地 | 阴影区 | 发暗，没有中间调 | 黄绿 | `4d7722` | 暂无，先记现象 | — | 先查是否可借已有黄绿补色 |

### 补色规则（来自组长 2026-11-27 答复，不是我定的）

1. **先查能不能用已有颜色解决**，再提补色。
2. 任何缺色**先走「色板补全」**，不要一上来就开专属色额度。补全额度：上限 20，已用 5（4 个黄绿 + 1 个深肤色），余 15。
3. 补色要**成套**：3~5 级明度，从邻近色相延伸，**登记进补全清单**，不要只补一个孤零零的颜色。
4. 原板已有色值**不改**。
5. 专属色另算：经营专属 ≤ 8；肉鸽专属每个可玩角色 / 怪物 8 色，共 ≤ 32（4 个角色）。UI 不加色，用 69 色的子集。

候选补色的色值和明度我不替她定。你只记「缺什么、缺在哪、猜想补什么」，色值最后由组长拍板（就像之前 5 个补色那样先出提案再核）。

每张图交这几样，放在 `alvinczq7-cell/art-prep/试压/`（建一个文件夹，名字自己定）：

三张都做完再汇总，组长看过才判定能不能冻板。

## 6. 常见坑

- **缩放没选最近邻**，会多出大量中间色，压色后到处是杂点。
- **一上来就开抖动**，会把缺色掩盖掉。第一轮必须无抖动。
- **色板没载对**：如果只载了 5 个补色，压出来会只剩那 5 色。导入后先数一下是 69 个。
- **把 5 色补色文件当整套用**：个人目录里的 `Endesga64-补色.gpl` 只有 5 个补色。
- **在原画上直接改**：另存新文件，原画不动。
