# 系统-升级

## 一句话

**钱买普通升级、稀有材料买高级升级、行动力管节奏，工资管持续消耗。** 四条腿一起，钱才留不住。

> 状态：**提案**，数字全是占位。
> **v2（2026-11-29）**：上一版价格太低 —— Claude PR #3 第 7 条直接写了「钱不是约束，W1 周净利 1.2~1.3 万，二楼 10 万不到 10 周就能买」。这版拆成多档、价格逐档递增，并补上持续消耗。

---

## 一、钱为什么会堆起来（上一版的病）

| 现状 | 数 |
|---|---|
| W1 周净利 | 1.2～1.3 万 |
| 52 周总收入（不涨价） | 约 **62 万** |
| 上一版所有升级加起来 | 约 **48 万** |

**总收入 > 总花费**，所以玩家 20 周后就开始「有钱没处花」。长周期游戏必须让总花费 **明显大于** 总收入，且分成很多小档，让玩家永远在追下一个目标。

---

## 二、四条门

| 门 | 管什么 | 现状 |
|---|---|---|
| **钱** | 能不能买 | 有 |
| **行动力** | 这周买不买得到（一周 14 点） | 有，但还没接到升级上 |
| **稀有材料** | 高级项专用，肉鸽精英 / Boss 掉 | 有（特殊道具 3%） |
| **工资** | 持续消耗，人越多越贵 | 只定了厨师长 2000/周 |

## 四、持续消耗：工资

光靠升级还不够，因为升级是一次性支出，买完就是自己的。工资才是每周都在吃钱的东西。

| 雇员 | 周薪 | 说明 |
|---|---|---|
| 厨师长 | **2000** | 已定（组长 11-28） |
| 新招的厨师 | **6000** | **已定（组长 11-29）**，现招按市场价 |
| 打怪的雇员 | 待定 | |

3 个厨师 = 2000 + 6000 + 6000 = **1.4 万/周**，占中后期收入的 25～35%。这样钱会持续流出去，不是只进不出。

> ⚠️ 这个数要一起生效：如果工资一直只有 2000，那 283 万的升级树也会被很快买空。

## 五、升级顺序（被 PR #3 修正过）

Claude 的模拟发现一个反直觉的地方：**座位是需求乘数，先买座位、后升厨房会让满足率塌掉。**

- 桌子升到 40 座 → 需求 22 → 30 份/天，一周肉从 170 涨到 210
- 二楼 80 座 → 需求 60 份/天，对 W1 厨房（32 份/天）是 2 倍的需求，**风评会一路滑**

所以正确顺序是 **厨房先追上，再扩座位**：

| 阶段 | 该买 | 不该买 |
|---|---|---|
| W1～W4 | 菜园 / 地窖 / 商店 / 桌子 | 不要碰二楼 |
| W4～W12 | **灶台 +1（把产能提到 56）** | 别买第二个座位升级 |
| W12～W20 | 菜园 2～3 档、地窖、商店 2 级 | |
| W20+ | 新楼层（产能已经够 80+ 再买） | |
| 后期 | 灶台 3～4 档、高级材料升级 | |

**问题**：现在的设计没有任何提示告诉玩家这个顺序。PR #3 的建议是加一个「推荐」引导 —— 比如计划单上标一句「今天客人 30 人，你的厨房只能做 22 份」。这条要不要做，还没定。
