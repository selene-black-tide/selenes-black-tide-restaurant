## 五条已经定死的项目参数

后面所有生成都必须照这个来，改之前先进 `decisions/` 写一条 ADR：

```
投影      isometric 2:1
光照      左上角来光（顶面 100% / 左墙 70% / 右墙 50%）
风格      高 hi-bit 像素 + 二次元
基准      960×540（1080p 整数 ×2 放大）
色板      Endesga 64 + 5 补色 = 69 色（原板不微调；每色系 3~5 级明度阶梯）
```

色板另有三条纪律：**UI 单独处理**（共用主色板，但只取高饱和 / 高亮档 + 独立语义色）、**专属色可加**、**批量出图前冻板**（冻的是色板文件 + 使用规则 + 明度阶梯，冻后改按 ADR）。

尺寸三层别混：**tile 32 / 场景 sprite 48–64 / 立绘约 400**，详见 [PixelLab入门.md](PixelLab入门.md) 第 4 节。
