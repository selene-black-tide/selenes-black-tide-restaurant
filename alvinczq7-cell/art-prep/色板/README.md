# AAP-64 色值文件（备用）

组长 2026-11-27 在群聊里选定 **AAP-64**（Adigun A. Polack，[Lospec 页面](https://lospec.com/palette-list/aap-64)，64 色）。

- `AAP-64.hex`：每行一个十六进制色值，按 Lospec 页面顺序，可导入 Aseprite 等。
- `AAP-64.gpl`：GIMP / Aseprite 通用调色板格式，按页面顺序。

**这只是 Alvin 个人目录里的备用副本，不是正式色板文件。** 色值抄自 Lospec 页面（2026-11-27 读取），已核对共 64 个且无重复。正式冻结的「色板文件 + 使用规则 + 明度阶梯」由组长定，冻结后的文件位置以她为准。

**授权**：Lospec 页面没有写授权条款，仅有页面本身的「免费下载」说明；使用前仍需核对 Lospec 使用条款，见 [色板方案](../色板方案.md)。
