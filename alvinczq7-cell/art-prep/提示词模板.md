# 出图提示词模板框架（草稿）

> **只有骨架，不预设画风。** 所有 `{大括号}` 都是待填项；画风相关的槽位要等「美术规范待决问题」拍板后才填。
> 团队方案（组长定）：**NAI 画原画 → 对着改像素**；**简单图标用 PixelLab**；经营部分 2D 做等距 3D 效果。
> tag 语法、顺序规则见 [NAI入门.md](../../docs/20-art/NAI入门.md)；等距参数见 [像素等距工作流.md](../../docs/20-art/像素等距工作流.md)。

---

## 0. 用法

1. 先在 [素材清单.md](素材清单.md) 里找到要出的东西，确认它的设定**已定**（标「待定」的别出，出了也是白出）
2. 复制下面对应的模板，只填已定的槽位
3. 每次出图把「填好的 prompt + 参数 + 日期」记到第 4 节的记录表，方便以后复现

> 记号约定：`{STYLE}` 这种全大写槽位 = **全项目共用**，定一次所有模板都用同一份；`{角色外观}` 这种中文槽位 = 每个素材自己填。

## 1. 全项目共用槽位（等团队拍板，现在全空）

| 槽位 | 填什么 | 现状 |
|---|---|---|
| `{STYLE}` | NAI 的全局画风前缀（画风 tag / 画师风格 tag / Vibe 参考图） | **待定** |
| `{NEGATIVE}` | NAI 的全局负向词 | 有基础版（见 1.1），可按实测增减 |
| `{NAI_MODEL}` | NAI 模型版本 | **待定** |
| `{QUALITY_TAGS}` | Quality Tags 开关开 / 关 | **待定** |
| `{PALETTE}` | 色板名 / 色数 | **待定** |
| `{OUTLINE}` | 描边方式 | **待定** |
| `{ICON_SIZE}` | 图标像素尺寸 | **待定** |
| `{TILE_SIZE}` | 等距砖块尺寸 | **待定** |
| `{ANCHOR_IMG}` | 风格锚 / 标准像（参考图） | 还没有 |

已定、可以直接写死的只有两条（[20-art/README.md](../../docs/20-art/README.md)）：

```
投影：isometric 2:1（经营部分）；平面 2D（肉鸽部分）
光照：light from upper left（顶面最亮、左墙中、右墙最暗）
```

### 1.1 基础负向词（来自 NAI入门.md 第 5 节，不涉及画风）

```
lowres, bad anatomy, bad hands, extra fingers, fewer fingers,
watermark, signature, username, text, logo
```

> NAI入门 里还列了 `heterochromia`（防异色瞳）。某个角色设定**本身**是异色瞳时，要从负向里去掉。

## 2. NAI 原画模板

### 2.1 角色设定图（标准像，最先做）

用途：每个角色先出一张设定图，挑 1 张定为「标准像」，后面所有差分都垫它。

```
{STYLE},
{1boy / 1girl / 其他主体}, solo,
character design sheet, multiple views, reference sheet,
{头发：长度 → 样式 → 颜色},
{眼睛颜色}, {肤色},
{头部配饰},
{上装：每件带颜色/材质},
{腰部},
{下装},
{手部}, {脚部},
{体型},
{手持物 / 标志性道具},
simple background, white background
```

负向：`{NEGATIVE}`

| 槽位 | 来源 |
|---|---|
| 主体、外观各项 | **只填[素材清单](素材清单.md)里写明的**；没写的空着，不要临时编 |
| 例：厨师长 | 目前文档只给了：壮汉、白衣、厨师帽、菜刀。其余槽位**等设定** |

### 2.2 肉鸽角色状态差分（基于标准像）

理念 2.9 定了 5 个状态：普通 / 攻击 / 受击 / 死亡 / 放技能。每个状态只换「动作段」，角色段**原样复制标准像那一份**。

```
{STYLE},
{角色段：从 2.1 原样复制，一个字都别改},
{构图：full body / cowboy shot},
{动作段},
{朝向：待定},
simple background, white background
```

| 状态 | 动作段（待填，下面只是写法提示） |
|---|---|
| 普通 | `{待机姿势}` |
| 攻击 | `{攻击动作 + 武器}` |
| 受击 | `{受击动作}` |
| 死亡 | `{倒地 / 消散等，看团队要不要做血腥}` |
| 放技能 | `{施法 / 蓄力动作 + 特效}` |

> 一致性优先用 NAI 的 Precise Reference / Vibe Transfer 垫标准像（NAI入门 第 7 节）。

### 2.3 敌怪原画

```
{STYLE},
{no humans / 1other / 物种 tag}, solo,
{物种 / 外形},
{体型大小},
{颜色与材质},
{特征部位},
{动作段：同 2.2 五个状态},
simple background, white background
```

> 目前只有**史莱姆**（精英 2，需小只 / 中只两种体型）和**大树精**（Boss）知道物种，其余敌怪外观待定。

### 2.4 物品 / 食材 / 遗物概念

```
{STYLE},
no humans, still life, {物品名 tag},
{形状}, {颜色与材质}, {特征细节},
simple background, white background
```

> 菜品「按颜色分品质」（理念 2.6）——品质色具体是哪几色**待定**，可能用在描边、底框或光效上，拍板后再加进槽位。

### 2.5 场景 / 建筑概念（给等距像素当参考）

```
{STYLE},
no humans, scenery, {场景名},
{视角：等距像素前的原画要不要直接画成 isometric view，待定},
{时间 / 光线：light from upper left},
{氛围},
{关键物件}
```

## 3. PixelLab 图标模板

> 组长决定 PixelLab **暂不充值**，先把模板备好。下面的参数名摘自 [像素等距工作流.md](../../docs/20-art/像素等距工作流.md) 和 PixelLab 网页常见选项，**真正开出图前要对着当时的官网 / API 文档核对一遍**（工具会改版）。

### 3.1 通用图标

描述（PixelLab 吃英文短句，越短越稳）：

```
{物品}, {关键形状}, {主色}, game icon, {朝向：front view / 3/4 view}, no background
```

参数槽：

| 参数 | 值 |
|---|---|
| 尺寸 | `{ICON_SIZE}` |
| 描边 outline | `{OUTLINE}` |
| 着色 shading | `{待定：平涂 / 少量阴影 / 细致阴影}` |
| 细节 detail | `{待定：低 / 中 / 高}` |
| 色板 | `{PALETTE}`（若工具支持导入色板） |
| 风格参考 | `{ANCHOR_IMG}`（第一个定稿图标做锚，之后全部垫它） |
| 透明底 | 是 |

### 3.2 战斗状态图标（可先做候选）

这批的 key 已经在术语表里，可以拿来练手和定图标规格：

| key | 中文 | 描述（只写「是什么」，形象待定） |
|---|---|---|
| `block` | 格挡 | `{待定}` |
| `strength` | 力量 | `{待定}` |
| `dexterity` | 敏捷 | `{待定}` |
| `rage` | 怒气 | `{待定}` |
| `bleed` | 流血 | `{待定}` |
| `slow` | 缓慢 | `{待定}` |
| `weak` | 虚弱 | `{待定}` |
| `intent` | 意图（攻击 / 防御 / 增益 / 减益） | `{待定}` |

> 同一批图标**一次性**用同一个风格参考出，别今天出三个明天出三个，否则描边粗细和色调会对不上。

### 3.3 等距砖块 / 摆件（经营部分）

参数（来自像素等距工作流 第 3 节）：

| 参数 | 值 | 说明 |
|---|---|---|
| `tile_type` | `isometric` | 已定 |
| `tile_view_angle` | `30` | 2:1 等距，已定 |
| 尺寸 | `{TILE_SIZE}` | 待定 |
| `tile_flat_top_px` | `{2 或 4}` | 待定 |
| `elevation` | `{0~12}` | 按物件高度 |
| `style_copy` | `["color_palette", "outline", "shading"]` | 锁光照用，等有风格锚后启用 |
| `outline_mode` | `{outline / segmentation}` | 待定 |

描述前缀（光照已定，其余待定）：

```
isometric, 2:1, {TILE_SIZE} tile, light from upper left,
top surface bright, left wall mid-tone, right wall dark,
{PALETTE 描述}, {物件描述}
```
