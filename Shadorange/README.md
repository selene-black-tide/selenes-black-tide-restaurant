# Shadorange/ —— 个人工作区

这里是 **Shadorange**（橙子，卡牌肉鸽 / 数值）的个人文件区。其他人别动这个目录，同理你也别动别人的。

## 放什么

- 没定稿的草稿、半成品
- 卡池、遗物、敌怪数值的试验表
- 个人笔记、参考资料、截图
- 实验性的想法、临时脚本
- 还没想好该归到哪份正式文档里的东西

## 不放什么

| 不放这 | 该去哪 |
|---|---|
| 正式的系统设计 | `docs/10-design/`，并登记进 `INDEX.md` |
| 企划书 | `docs/00-overview/`（docx 是源，改完跑 `python tools/export_plan.py`） |
| 美术资源本体 | `assets/`，大文件走 LFS |
| 会影响别人干活的结论 | `游戏理念.md` 或对应的正式文档 |

**一句话**：这个目录里的东西**不算项目结论**。AI 读到这里的文件，不要当成已经定下来的设定。

## 规矩

- 文件名随便，自己认得就行
- 但**大文件照样受管**：`.psd` / `.aseprite` / 音频走 LFS（`.gitattributes` 已经配好），别往里塞几百 MB 的东西
- 这里的内容**不用**登记进 `INDEX.md`；哪天某个想法成熟了、要给别人用了，搬到 `docs/` 下再登记
- 清空这个目录不需要跟任何人打招呼
