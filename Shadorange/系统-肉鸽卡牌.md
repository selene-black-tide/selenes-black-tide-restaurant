# 系统-肉鸽卡牌

> 本文是 `游戏企划书` 与 `游戏理念.md` 里肉鸽部分的**拆解与工作台**，不是新的结论来源。
> 数值以 `docs/00-overview/游戏企划书.docx` 为准；本文只做索引、补齐接口、记录待定。

## 一句话

每周一次的下地牢：回合制卡牌战斗，用**体力条**（`stamina`）而不是限时来限制推进深度，带回食材、菜谱和遗物，反哺第二天的经营。

## 机制

### 一局的骨架

进地牢 → 逐房间推进（战斗 / 事件 / 掉落）→ 体力见底或主动撤退 → 回店结算。

体力**同时是战斗内的出牌资源**和**整局的续航**——这是 11-25 把「费用」和「限时」二合一的结果，也是本作和尖塔最大的区别。代价是两条曲线被绑在一根条上：出牌越猛，走得越浅。

### 战斗

1. **玩家回合**：抽 5 张，出牌（每张扣体力），可用道具
2. **回合结束**：无其他能力则弃掉全部手牌
3. **敌方回合**：按意图行动；一个敌人可以执行一个或多个意图

### 掉落物（企划书已定三类）

1. **厨房原料**：神秘肉类、神秘调料（名字后定）
2. **高级升级素材**：普通升级用钱，后期高级升级要素材
3. **增益道具**

> 荤的靠肉鸽、素的靠种田，所以肉类是肉鸽的主产出；调料和菜谱是第二条产出线。

## 角色 1（初始角色）

定位：无脑抽卡灌伤，强度中上（参考小骑士 / 尖塔战士），比较肉。**初始生命 50**，个人能力：**每回合多抽一张牌**（即抽 6）。

**初始卡组（9 张）**

| 卡 | 张数 | 效果 |
|---|---|---|
| 打击 | 4 | 打 6 |
| 防御 | 4 | 防 5 |
| 重击 | 1 | 打 20（独有） |

**可选 · 攻击（6 张）**

| 卡 | 效果 |
|---|---|
| 双重打击 | 打 5×2 |
| 盾反 | 打 5 防 5 |
| 迅捷打击 | 打 7 抽 1 |
| 横劈 | 对所有敌人造成 7 点伤害 |
| 全力打击 | 打 25，自身获得一层虚弱（下回合攻击伤害 −50%） |
| 多重打击 | 造成 6 点伤害，次数 = 手牌中攻击牌数目（含自身） |

| 卡 | 效果 |
|---|---|
| 激怒 | 获得 5 点怒气（`rage`），怒气加到下次攻击数值上 |
| 凝神 | 获得 4 点敏捷（`dexterity`），1 点敏捷 = 下次防御 +1 |
| 疾速 | 抽 3 |
| 招架 | 获得 8 点格挡（`block`），对敌人反弹被格挡的伤害 |

| 重甲 | 防 13，获得一层缓慢（下回合防御 −25%） |
| 锻炼 | 获得 2 点力量（`strength`，跨回合保留，1 点力量 = 伤害 +1） |

**可选 · 能力（4 张）**

| 卡 | 效果 |
|---|---|
| 越战越勇 | 每造成 10 点伤害，抽 1 张 |
| 省力 | 卡牌耗能 −25% |
| 拉伸 | 每造成 5 点伤害，获得 1 点格挡 |
| 刺伤 | 每对敌人造成一次伤害，施加一层流血（`bleed`）；下次伤害 = 卡面 + 流血层数 |
