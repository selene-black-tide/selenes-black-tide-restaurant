# 角色1 文本试玩原型

> **状态：实验性原型，不是设定。**
> 怪物数值全部按 2026-11-28 橙子给的怪物表录入，一个没改。楼层排布是原型暂定的（见下），
> 尚未拍板。

## 跑起来

```bash
python game.py                # 正常玩
python game.py --seed 42      # 固定随机种子，方便复盘
python game.py --stamina 70   # 改整局体力，测平衡用
python sim.py 500             # 机器人跑 500 局，出层数分布
python sim.py 500 100         # 500 局，指定体力 100
```

Python 3.8+，零第三方依赖。

## 规则（橙子定的）

- **整局体力 100 点**，出牌消耗，见底回店
- **所有卡牌耗 1 点体力**
- **没有回血**：打完不会自己回血
- **能力牌打出后消耗**：进「消耗」堆，本局不再回到牌堆，能力效果保留到回店
- **牌库分四堆**：抽牌堆 / 手牌 / 弃牌堆 / 消耗堆；抽牌堆空了洗回弃牌堆；回合结束手牌全进弃牌堆
- **层数无上限**，7 层一个循环

## 一局怎么走

```
1 入口·苔径     敌怪1
2 积水走廊      敌怪2
3 碎石阶       敌怪3
4 湿洞         三小只
5 巢穴外缘      强怪（敌怪5 / 6 / 7 随机）
6 精英·锈铁门    精英（精英1 / 精英2 史莱姆 随机）
7 树心         大树精
```

第 8 层回到第 1 层，楼层名后面会标「（第 2 圈）」。**第 5、6 层用哪个怪是原型暂定的**，
原始设计没说这一圈具体怎么排，橙子看到可以改。

### 精英

**精英1**：92 血，打 18 → 力量 +5 → 打 23。

**精英2（史莱姆）**：开局四小只，每只 20 血。

- 小只意图：打 4 → 施加虚弱且力量 +2 → 打 6
- 中只意图：打 8 → 施加虚弱且力量 +4 → 打 12
- **合体**：玩家回合结束时，若有小只血量 ≤ 6，与相邻小只合体成 30 血中只；
  若还有 ≤6 的小只，继续融进中只，每只 +15 血
- **分裂**：中只被击败，原地裂成两只 10 血小只

### Boss

**大树精**：280 血，施加 6 层缠绕 → 打 21 → 力量 +5 → 打 26。
缠绕每层每回合掉 1 血，可叠加。

## 测试结果（500 局，体力 100）

| 指标 | 数值 |
|---|---|
| 平均层数 | **5.9 层** |
| 中位数 | **6 层** |
| 25% / 75% 分位 | 6 层 / 6 层 |
| 最远 / 最近 | 12 层 / 4 层 |
| 结束原因 | 体力见底 **63%**、生命归零 **37%** |

**一局基本固定死在 Boss 门口。**

| 卡在哪 | 死亡 | 体力耗尽 |
|---|---|---|
| 树心（Boss） | 33% | 46% |
| 精英·锈铁门 | 4% | 13% |
| 巢穴外缘（强怪） | 1% | 0% |

300 局单独统计：

- **84% 能摸到 Boss，只有 4% 打得死**
- 进 Boss 时平均剩 **18.8 体力**、**35.3 生命**
- 大树精 280 血，按当时的卡组和伤害，打完它大概要 30+ 张牌，而兜里只有 19 点体力

## 需要注意的几件事

1. **Boss 是硬墙，不是曲线。** 前 6 层平均每层 13–14 点体力，到树心只剩 19 点，而 280 血要 30 张牌以上。现在的「无限层」实际是「第 7 层到此为止」。
2. **血量和体力现在都在起作用了。** 改数值前是 100% 体力见底、剩 42 血；现在 37% 死因是血，剩 15.8 血，两条资源都上桌了。
3. **敌怪2 在 2 层就打 23。** 打过 +10 力量之后一发 23，而角色只有 50 血、每回合 6 张牌，它比同层另外两只狠一档。
4. **史莱姆的合体很难触发。** 要求「剩 ≤6 血还站着」，但打击 6 点、重击 20 点，多数情况是一击打死而不是打到残血，所以实战里合体少见、分裂常见。
5. **第 2 圈的怪和第一圈一样**，所以 12 层是极少数幸运局。

## 原型自补的规则（不是设定）

| 项 | 原型做法 | 为什么 |
|---|---|---|
| 楼层排布 | 5 层强怪随机、6 层精英随机 | 原始设计只给了怪物池，没给每层放什么 |
| 省力 | 每第 4 张牌免费 | 全卡 1 体力，−25% 没法取整 |
| 15 血小只的意图 | 与 20 血同款 | 只给了两套意图、三只小只 |
| 合体选目标 | 就近相邻的一对 | 原始描述「旁边的小只」没规定左右 |
| 失败 | 掉落全丢 | 待拍板 #8 先挑一个跑通 |
