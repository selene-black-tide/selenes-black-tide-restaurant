## 一、厨房

厨房能力 = 灶位 × 营业时长。灶台数量由厨房等级决定，决定并行效率；营业时长由雇员（厨师）决定，等级越高，每天能工作的时间越多。

做菜总时长（min）= Σ〔每个做饭雇员的「能力加成 × 该雇员工时（h）」〕× 60

eg.W1 一个灶台，厨师长 ×2、8h → 2×8×60 = 960min
eg.W2 两个灶台，厨师长 ×2 + 新员工 ×1.5、各 8h →（2×8 + 1.5×8）×60 = 1680min
eg.W3 三个灶台，再加一人 ×1.8、各 8h →（2×8 + 1.5×8 + 1.8×8）×60 = 2544min

### 计算规则

**加成走加法**：每加一个人只加自己那一份，不能把倍率连乘（连乘是指数增长，W3 就到 7776）。
**一灶一人**：灶台 = 并行工位上限，在岗雇员数不能超过灶台数。
每道菜从总时长里扣自己那份耗时，扣完为止：扣不完 = 有产能白废，超了 = 做不完。
员工也要给他们发工资，厨师长是一周 2000￥，其他的后面定。

## 四、风评结算【修订】

每天营业结束后结算一次，三块分开算，最后加总。

### ① 满足率

s = min（实际供上的份数 ÷ 当天需求份数, 1）
Δ风评 = 1.0 × (s − 0.9)

### 口径

1 份菜 = 1 道菜。客人平均点 2~3 道，所以「当天需求份数」= 当天来客数 ×（2~3）；来客数上限 = 座位数。
「供上份数」= 实际端出去、被吃掉的份数，封顶 = 需求份数。做多了不进 s，剩菜只浪费食材。
**0.9 是及格线**：只喂饱九成人 → 不涨不跌；低于九成按缺口比例扣。
k=1.0、s₀=0.9 的锚点：满座全喂饱 → +0.1/天 → 一周年（364 天）约 +36 分。想慢一倍就把 1.0 改回 0.5。

### ② 特殊菜

**按第三节**：每个 +0.15，不并进 s。

### ③ 暴毙

午夜班结束，若当天菜单含怪物肉类菜品、且至少卖出 1 份 → 掷一次 5%。
中了 → 一位客人暴毙：风评 −0.3。
白天班不掷。
期望 −0.015/天，比满分日的 +0.1 小一个量级。

### ④ 【修订】删掉的两条

做好一个菜，风评 +0.005 —— 和满足率算的是同一件事（32 份给 +0.16，会把 −0.185 抵消成 −0.025），删。
没拿到菜，风评 −0.1/份 —— 已被满足率吸收，删。

### 验算

| 场景 | s | Δ风评 |
|---|---|---|
| 产能不足（供 32 / 需 60） | 0.53 | −0.37 |
| 刚好及格（供 54 / 需 60） | 0.90 | 0 |
| 满座喂饱（供 60 / 需 60） | 1.00 | +0.10 |
| 多做（供 80 / 需 60） | 1.00 | +0.10（多的 20 份只浪费食材） |
| 完成 1 个特殊菜 | — | +0.15 |
| 暴毙一次 | — | −0.30 |

### 自平衡

风评 ↓ → 来客 ↓ → 需求份数 ↓ → s 回升 → 风评稳住。

所以"初期做不满"不会一路归零，会稳定在「产能刚好吃满当天客人」的水平。玩家想把风评推上去，唯一的路是把产能（灶台 × 雇员 × 工时）推到覆盖满座需求。

## 主线剧情设计

男主即玩家，在某一天莫名其妙地接受了老家的半荒废的餐馆，是过世的爷爷留下来的。他开始经营这个餐厅，发现甚至没有厨师得自己下厨，而且人来的可怜，不停地亏钱。但餐厅里的装修却不破烂，反而精致。负责“采购”的大叔第一天就说不干了，回家了。他很好奇爷爷的钱是从哪里来的。于是他半夜走进了后院那总是充满雾的山林，发现了非人类的怪物，然后被追着跑。他遍体鳞伤，快跑回餐馆时，一位身穿白衣头戴厨师帽的壮汉，拿菜刀将怪物一刀两段。
后来他向男主介绍，自己是刚刚休假回来的厨师长，他并不知道男主爷爷已经过时了，感到震惊与蹊跷（这里开始埋伏笔了）。随后他给男主讲述了这个新的世界观：后山就是名为“雾葬橡林“的异空间，里面有很多攻击性强的怪物，被称为“异兽”，他们不会跑出来。这些异兽身上的肉特别多，好吃又营养，有些还会随身携带一些有着特异功能的物品。男主这时惊醒，原来第一天那位负责“采购”的健壮大叔是猎人。男主询问这些肉吃了没事吗。厨师长说，当然会有，所以在良心下卖人类卖的少。主要的赚钱手段是，在夜晚，闭馆之后，启动后院的魔法阵，打开异界大门，就会有很多异界的顾客过来吃饭。这些顾客不是异兽，而是有着与人类同样智慧的“异族”。当然，这些都是人类对它们 的称呼。后院的魔法阵还有隔绝外部世界的作用。大家就是与非人的生物达成了微妙的交易关系，保持和平。男主感到不可思议。
当晚，厨师长以神秘的点火仪式启动了魔法阵，男主看到有许多异界的顾客从魔法门中涌入。他们叽叽喳喳说着什么，男主听不懂——厨师长给他翻译，说是他们快一个周没吃上这里的菜了，感到很气愤。厨师长承诺，一周后就能成功开张，把他们赶了回去。
就这样，男主开始了Week1的模拟经营。首先是把负责的采购的大叔找了回来，又是找了个美少女当厨师。然后就是肉鸽，经营了。

“这个采购的大叔就当成你设计的第一个角色吧”
