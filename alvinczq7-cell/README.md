| 方向 | 说明 |

- 参考资料、截图
- 还没想好该归到哪份正式文档里的东西

## 不放什么

| 不放这 | 该去哪 |
|---|---|
| 正式的美术流程 / 规范 | `docs/20-art/`，并登记进 `INDEX.md` |
| 美术资源本体（定稿要用的） | `assets/`，大文件走 LFS |
| 代码 | `src/`，走 PR |
| 会影响别人干活的结论 | `游戏理念.md` 或对应的正式文档 |

**一句话**：这个目录里的东西**不算项目结论**。AI 读到这里的文件，不要当成已经定下来的设定。

## 规矩

- 文件名随便，自己认得就行；子目录名照样用英文（AGENTS.md 的 R6）
- **大文件照样受管**：`.psd` / `.aseprite` / 音频走 LFS（`.gitattributes` 已经配好）
- 这里的内容**不用**登记进 `INDEX.md`；哪天要给别人用了，搬到 `docs/` 下再登记
