# Endesga 64 + 补色提案

> **这是提案，待组长定。** 组长倾向 Endesga 64（群聊，经 Alvin 转述），但它的黄绿只有 2 色，撑不起「3~5 级明度」。Alvin 同意先出一版「原板 + 补色」给组长看。
> **注意和她定的「不微调」的关系：** 补色后总数是 69 色，不是 64，要不要为黄绿开这个例外、还是算「专属色」（她说过专属色可以加），都由她定。**不是 ADR，也不是冻结。**

## 1. 补哪些色

| 色值 | 用途 | HSL 中的明度 L |
|---|---|---|
| `#314e18` | 暗橄榄 / 深黄绿 | 0.20 |
| `#4d7722` | 中暗黄绿 | 0.30 |
| `#6da52c` | 中黄绿 | 0.41 |
| `#8fd039` | 中亮黄绿 | 0.52 |
| `#6f462f` | 深肤色（补在 `#8a4836` 和 `#5d2c28` 之间） | 0.31 |

原板黄绿 `#99e65f`（L 0.64）、`#d3fc7e`（L 0.74）。补 4 个之后黄绿共 **6 级**，相邻两级明度相差约 0.10~0.12，符合「3~5 级」的要求（并留有余量，用法上可以每次只挑其中 3~5 级）。

## 2. 怎么选的（让组长能判断合不合理）

- 色相取 86°~92°，贴着原板黄绿（99e65f 约 94°、d3fc7e 约 80°），不往绿边跑，避免和原板的绿色（约 114°、134°）撕裂。
- 饱和度随明度从低到高（0.52 → 0.62），和原板「暗色饱和度 0.5~0.6、亮色 0.7 以上」的走势一致。
- 深肤色取色相 21°、饱和度 0.41，比原板 `#8a4836` 的红棕更偏棕。
- **这些色值是我按数值计算的提案，没有经过真实画面验证**，应该拿一张 NAI 原画试压后由组长用眼睛定。
