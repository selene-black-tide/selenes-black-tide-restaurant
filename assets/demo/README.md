## 加新资产时

- 文件名用中文、说明性名字（`餐厅部分示意图.jpg`、`厨房灶台-3级.png`）
- 概念稿和定稿分开标注：文件名带「示意图 / 概念稿」的都是参考，正式资产直接写名字
- `.psd` / `.aseprite` 走 Git LFS（`.gitattributes` 已配好），`.png` / `.jpg` 走普通提交；单张超过 5 MB 先问一句
- 不确定归 demo 还是 run，问一句，别乱放
